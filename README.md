# MAYDAY ICONIC 2026

Fanowski licznik do 10 listopada 2026, godz. 17:00 czasu polskiego. Strona statyczna, bez instalacji i bez własnego serwera.

## GitHub Pages

1. Utwórz publiczne repozytorium `mayday-2026` na https://github.com/new.
2. Wgraj `index.html`, `social.png` i `.nojekyll` bezpośrednio do głównego katalogu repozytorium. Nie wgrywaj pliku ZIP.
3. Wejdź w Settings > Pages. W sekcji Build and deployment wybierz Deploy from a branch, następnie `main` i `/ (root)`, i zapisz.
4. Po publikacji strona będzie dostępna pod adresem pokazanym przez GitHub Pages.
5. Dla niezawodnej miniatury WhatsApp zmień `content="./social.png"` w tagu `og:image` na pełny adres opublikowanego obrazka, np. `https://LOGIN.github.io/mayday-2026/social.png`. Dodaj też tag `og:url` z adresem strony.

Miniatura jest statyczna. Żywy licznik działa po otwarciu linku. WhatsApp może przechowywać wcześniejszą miniaturę w pamięci podręcznej.

Godzina jest zapisana z przesunięciem +01:00 obowiązującym w Polsce w listopadzie. Wynik zależy od poprawnie ustawionego zegara urządzenia. Licznik zatrzymuje się na zerze po rozpoczęciu wydarzenia.
